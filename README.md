# Happy Birthday Ingol — Multi-Page Website 🎂✨

## Pages & Transitions
1. **23 NOV 2026 Candle Page** → *Envelope Transition* into Page 2
2. **Happy Birthday Ingol + Photo Ribbon** (no scrollbar, fits screen width) → *Curtain Transition* into Page 3
3. **Draggable Polaroid Board + Clickable Butterflies** → *Envelope Transition* into Page 4
4. **"didn't realise when we reached from here to here"** (`before.jpg` & `after.jpg`) → *Curtain Transition* into Page 5
5. **Ingol's 3D Starfield Galaxy** → *Envelope Transition* into Page 6
6. **iPhone Chat (`ingol`)**

## Setup
1. Put numbered photos (`1.jpg`, `2.jpg`, ...) plus `before.jpg` and `after.jpg` inside `images/`.
2. Run `python update_photos.py` if you add more than 6 numbered photos.
3. Open `index.html` in any browser.
